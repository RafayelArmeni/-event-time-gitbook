# Theme settings

Theme settings change the whole site at once. Open any Event Time page in the editor, click the **Theme** icon in the left sidebar, then **Edit theme settings**.

## Brand

| Setting | What it does |
|---|---|
| **Primary color** | Main brand color, used for buttons, highlights and the start of the gradient. |
| **Secondary color** | Second brand color, used for accents. |
| **Heading font** | Font for headings. Default: Titillium Web. |
| **Body font** | Font for text. Default: DM Sans. |

## Colors

| Setting | What it does |
|---|---|
| **Color scheme** | **Dark** or **Light**. This is the default for all pages. The three light home templates are always light. |
| **Page background**, **Card background**, **Raised card background**, **Border color**, **Muted text color**, **Link color** | Colors for the dark scheme. |
| **Gradient end color** | The second color of the brand gradient used on buttons and highlights. |

**Light scheme colors** has the same settings for light pages, plus heading, text and accent text colors.

## Buttons

| Setting | Default |
|---|---|
| **Use gradient on primary buttons** | On. Turn it off for solid primary-color buttons. |
| **Corner radius** | 999 (fully rounded). Use 0–8 for square buttons. |
| **Vertical padding** / **Horizontal padding** | 15 / 32 px |
| **Text style** | Uppercase or Normal |

## Layout

| Setting | Default |
|---|---|
| **Maximum content width** | 1240 px |
| **Section spacing on desktop** | 110 px |
| **Section spacing on mobile** | 72 px |
| **Card corner radius** | 16 px |

## Header

* **Transparent header at the top of the page** (on by default)
* **Sticky header** (on by default)
* Header background when scrolled, menu link color and menu link hover color, for dark and light pages

## Blog

Turn blog features on or off: topic filter, reading time, author on post cards, share buttons, topics under posts, author box, related posts, subscribe form on the listing and the ticket banner under posts.

## Footer

Footer background, heading color, text color and link hover color.

!!! note

    To change just one section instead of the whole site, use that section's **Style** tab. See [Section style and the Style tab](style-tab.md).
