# Speakers, testimonials and photo gallery

## Speakers

A grid of speaker cards.

| Field | Notes |
|---|---|
| Speakers | Photo, name, job title, company, LinkedIn URL, X (Twitter) URL and an optional profile page link. |
| Speakers per row on desktop | Usually 4. Phones show fewer automatically. |
| Button below the speakers | For example "See all speakers". |

!!! note

    Use square photos of the same size (at least 600 × 600 px) so all cards line up.

## Testimonials

Attendee or customer quotes with five layouts.

| Field | Notes |
|---|---|
| Testimonials | Quote, author name, job title, company, photo, company logo, star rating, review date, review source and an optional video testimonial. Turn on **Feature this testimonial** to make one stand out. |
| Layout | **Carousel**, **Grid**, **Masonry wall**, **Featured spotlight** or **Simple list**, with columns for desktop, tablet and mobile, carousel options and quote length. |
| Structured data | Optionally adds review data (JSON-LD) for search engines. Only use it for genuine reviews. |
| Styles tab | Colors, card style, ratings and more, separate from the other modules. |

Video testimonials load only when a visitor clicks play, so they don't slow the page down.

## About with video

An event introduction with a video.

| Field | Notes |
|---|---|
| Section heading | |
| Highlights | Short title and text pairs, for example "60+ speakers". |
| Button | Optional. |
| Video | Thumbnail image and a **YouTube or Vimeo URL**. The video opens in a lightbox. A badge number and text can sit on the thumbnail, for example "8th edition". |
| Key numbers | Number and label pairs, for example "1,200 attendees". |

YouTube videos load from the privacy-friendly youtube-nocookie.com domain.

## Photo gallery

A photo grid with a full-screen viewer.

| Field | Notes |
|---|---|
| Layout | **Mosaic (first photo large)** or **Even grid**. |
| Photos per row on desktop | |
| Photos | Photo and optional caption. |
| Open photos in a full-screen viewer | Visitors can click through the photos with arrows or the keyboard. |
| Button below the gallery | Optional. |
