# Venue, info cards and FAQ

## Venue map

Venue details with an embedded Google map.

| Field | Notes |
|---|---|
| Venue name, Address | Shown in a card next to the map. |
| Map search | What the map searches for, for example "Lisbon Congress Center". Use the venue name plus city, or the full address. |
| Map zoom | Higher numbers zoom in closer. |
| Dark map colors | Darkens the map to match dark pages. |
| Directions button text | Opens Google Maps directions to the venue. |
| Travel tips | Icon, title and text, for example "From the airport". |
| Map position on desktop | Right or left. |

No Google API key is needed.

## Info cards

Flexible cards for hotels, perks, benefits or features.

| Field | Notes |
|---|---|
| Cards | Photo **or** icon, badge, small detail line, title, text, link text and link. |
| Cards per row on desktop | |
| Section background | **Page background** or **Tinted band**. |

Examples from the demo: partner hotels with photos and "Book a room" links, travel tips with icons, sponsor benefits.
