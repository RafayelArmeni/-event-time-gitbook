# Thank you and error pages

## Thank you

The confirmation after someone registers. Set your registration form to redirect to the page that uses this module (see [Forms and the registration flow](../getting-started/forms-and-registration.md)).

| Field | Notes |
|---|---|
| Eyebrow text, Heading, Text | For example "See you in *Lisbon*!" |
| Ticket card | Event name, ticket type, date, time, location and small print, shown as a ticket. |
| Add to calendar | Event title, start, end, location and description. Adds a **Google Calendar** button and a calendar file button for Apple Calendar and Outlook. |
| Next steps | Heading and a list of title and text pairs, for example "Check your inbox". |
| Primary button, Secondary button | |
| Share | Share links with a page to share and a message, so attendees can invite colleagues. |
| Show confetti | A short confetti burst when the page opens. It's skipped for visitors who prefer reduced motion. |

## Error page

Used on the 404 and 500 system pages.

| Field | Notes |
|---|---|
| Error code | Shown large, for example "404". |
| Eyebrow text, Heading, Text | |
| Primary button, Secondary button | For example "Back to home" and "View schedule". |
| Site search | Show a search field, its placeholder, button text and the search results page path. |
| Helpful links | Heading plus link text and links to your main pages. |
