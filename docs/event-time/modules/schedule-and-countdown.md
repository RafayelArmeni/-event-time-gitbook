# Schedule and countdown

## Schedule tabs

The event agenda, with one tab per day.

| Field | Notes |
|---|---|
| Section heading | Eyebrow, heading, intro and alignment. |
| Days | Add one item per day: **Tab label** (for example "Day 01") and **Date**. |
| Sessions (inside each day) | Time, session title, description, speakers, room or location and session type. |
| Session type | **Keynote**, **Workshop**, **Panel**, **Networking** or **Break**. Each type is shown as a badge on the session card. |
| Layout | **Cards** or **Timeline**. |
| Button below the schedule | Optional, for example "Download the full agenda". |
| Labels | The badge names and the speaker prefix. Translate them if needed. |

!!! note

    A one-day event? Add just one day. The tabs are hidden when there's only one.

## Countdown

A large countdown to the event start, with a button.

| Field | Notes |
|---|---|
| Eyebrow text, Heading | |
| Event start date and time | The moment the countdown counts down to. |
| Countdown labels | Days, hours, minutes, seconds, and the text to show after the countdown ends. |
| Button | For example "Get your ticket". |
| Background image | Optional. |

## Marquee strip

An endless scrolling band of large text, for example "60+ speakers ✦ Lisbon, Portugal ✦ February 24–25". Place it between sections.

| Field | Notes |
|---|---|
| Items | One text per item. |
| Style | **Gradient band**, **Outlined text** or **Dark band**. |
| Seconds per loop | Higher is slower. |
| Direction | Right to left or left to right. |
| Tilt the band | Slightly rotates the band for a bolder look. |

Visitors can pause the animation with the pause button, and it doesn't move for visitors who turned on "reduce motion" on their device.
