# Forms, banners and blog posts

## Contact form

A HubSpot form in a card, next to contact details.

| Field | Notes |
|---|---|
| Section heading | |
| Contact details | Icon, title, text and an optional link (for example a `mailto:` link). |
| Social links | Heading, network and profile URL. |
| Form card | Heading, text and the HubSpot form. |

Use it for contact, speaker applications, sponsor enquiries or meetup RSVPs.

## Newsletter signup

A simple signup section.

| Field | Notes |
|---|---|
| Eyebrow text, Heading, Text | |
| Form | A HubSpot form, usually with just an email field. |

## Call to action banner

A bold banner, for example "Become a sponsor" or "Tickets are selling fast".

| Field | Notes |
|---|---|
| Eyebrow text, Heading, Text | |
| Primary button, Secondary button | |
| Background | **Brand gradient**, **Image** or **Card color**. |
| Background image | Used when the background is **Image**. |
