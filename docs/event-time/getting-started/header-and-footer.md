# Header and footer

The header and footer are **global**: you edit them once and the change appears on every Event Time page.

To edit them, open any Event Time page in the editor, click the header or footer, then click **Open global content editor**.

## Header

| Setting | What it does |
|---|---|
| **Logo** | Your logo. Use a light version, because the default header is dark. |
| **Logo height** | Height of the logo in pixels. |
| **Logo on light pages** | A dark version of your logo, used on the light home templates. |
| **Logo link** | Where the logo links to, usually your home page. |
| **Menu** | The navigation menu to show. Create menus in **Settings › Content › Navigation menus**. |
| **Menu levels** | How many dropdown levels to show. |
| **Language switcher** | Shows a language menu when the page has translations (see below). |
| **Header button** | The button on the right, for example "Get tickets". |
| **Top bar** | An optional thin bar above the header with the event date, email, phone and social links. |
| **Labels and screen reader text** | Text for the mobile menu buttons and skip link. Translate these if your site isn't in English. |

## Language switcher

If your site is in more than one language, the header shows a language menu with a globe icon. It lists the current language and every published translation of the page, and takes visitors to the same page in the language they choose.

1. Create a translation of a page: open the page in the editor and choose **File › New › Multi-language variation**.
2. Publish the translation. The switcher appears automatically on both versions.

Pages without translations don't show the switcher. To hide it everywhere, turn off **Show language switcher** in the header's **Language switcher** settings. Translate **Button text for screen readers** if your site isn't in English.

The header is transparent at the top of the page and sticky while scrolling. You can change both in **Theme settings › Header**.

## Footer

| Setting | What it does |
|---|---|
| **Brand** | Footer logo, logo link, a short about text and social links. |
| **Link column 1** and **Link column 2** | A heading and a navigation menu for each column. |
| **Contact column** | Address, email and phone number. |
| **Bottom bar** | Copyright text and an optional legal links menu (privacy policy, terms). |

Footer colors are in **Theme settings › Footer**.

!!! warning

    If a footer column is empty on your site, it's because no menu is selected for it yet. Choose a menu in **Link column 1** and **Link column 2**.
