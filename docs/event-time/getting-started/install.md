# Install the theme

## 1. Get the theme

1. Open the [HubSpot Template Marketplace](https://ecosystem.hubspot.com/marketplace/website) and search for **Event Time**.
2. Click **Get** (or **Buy**) and choose your HubSpot account.
3. HubSpot adds the theme to **Content › Design Manager** under `@marketplace`. You don't need to download anything.

## 2. Set it as your active theme (optional)

If Event Time will power your whole website:

1. Open the **Themes** page in HubSpot (type "Themes" in the HubSpot search bar to find it).
2. Find **Event Time** and click **Set as active theme**.

You can also use Event Time for one event site next to your existing theme. Just pick an Event Time template when you create a page.

## 3. Set your brand

Before building pages, open **Edit theme settings** and set:

* **Primary color** and **Secondary color** (your brand colors; they make the gradient)
* **Heading font** and **Body font**
* **Color scheme**: Dark or Light

See [Theme settings](../customize/theme-settings.md) for every option.

!!! note

    To open theme settings, edit any Event Time page, click the **Theme** icon in the left sidebar of the page editor, then **Edit theme settings**.
