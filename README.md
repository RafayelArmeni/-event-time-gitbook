# Pixtheme Docs

Source for https://docs.pixtheme.com, built with MkDocs Material.

- Event Time docs: `docs/event-time/`
- Menu: `nav` in `mkdocs.yml`
- Preview locally: `pip install -r requirements.txt && mkdocs serve`

Publish: `mkdocs gh-deploy` builds the site and pushes it to the `gh-pages` branch
(repository Settings › Pages › Source: Deploy from a branch › `gh-pages` / root).
