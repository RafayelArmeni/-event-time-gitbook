# Section style and the Style tab

Every Event Time module has a **Style** tab in the page editor. Use it to make one section look different from the rest of the page. Empty fields keep the theme design, so you only set what you want to change.

![Dark and light sections](../.gitbook/assets/dark-light.jpg)

## Section style

The quickest way to change a section. Choose one of:

| Option | Result |
|---|---|
| **Same as the page** | Follows the page's dark or light scheme (default) |
| **Dark** | Dark section, even on a light page |
| **Light** | Light section, even on a dark page |
| **Tinted background** | A softly colored background to separate the section |
| **Brand gradient** | Full brand-gradient background with white text, great for call-to-action sections |

{% hint style="success" %}
**Tip:** alternate **Same as the page** and **Tinted background** down a long page to give it rhythm without changing any colors.
{% endhint %}

## Custom styles

For full control, open **Custom styles**:

| Group | Settings |
|---|---|
| **Spacing** | Space above and below the section, on desktop and on mobile |
| **Background** | Background color, background image, image overlay color and image position |
| **Text colors** | Headings, body text, secondary text, small labels, highlighted words and links |
| **Cards** | Card background, card border and card corner radius |
| **Buttons and accents** | Gradient start and gradient end colors for this section's buttons and highlights |
| **Hover and active states** | Button hover background and text, link hover color, card hover border and background, active background and text (for example the selected day tab or an open FAQ question) |

Custom styles work on top of the section style. For example, choose **Light** and then set a custom card background.

{% hint style="info" %}
The **Testimonials** module has its own, larger **Styles** tab with layout-specific options.
{% endhint %}
