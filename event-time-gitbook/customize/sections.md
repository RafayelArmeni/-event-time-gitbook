# Ready-made sections

Sections are pre-built blocks with demo content that you can drop into any page made with a drag-and-drop template.

In the page editor, click **+** (Add) › **Sections**, then look for:

| Section | Contains |
|---|---|
| **Event hero** | Opening section with heading, date, location, buttons and countdown |
| **About with video** | Intro text, highlights, key numbers and a video in a lightbox |
| **Schedule tabs** | Agenda with one tab per day |
| **Speakers** | Speaker grid |
| **Countdown** | Large countdown with a button |
| **Ticket pricing** | Three ticket cards with a highlighted plan |
| **Testimonials** | Attendee quotes |
| **FAQ** | Questions and answers |
| **Call to action banner** | Bold banner with two buttons |
| **Newsletter** | Signup form |

You can also save your own edited sections: hover over a section in the editor, click **Save section** and reuse it on other pages.
