# Hero, page intro and coming soon

## Hero

The large opening section of a home page.

| Field | Notes |
|---|---|
| Eyebrow text, Heading, Intro text | Mark words in the heading with `*asterisks*` to highlight them. |
| Event details | Date and location, shown with icons. |
| Primary button, Secondary button | For example "Get your ticket" and "View schedule". |
| Countdown card | Show a countdown card with a title and the event start date and time. |
| Background | Background image, overlay darkness and glowing shapes. |
| Layout | **Text left, countdown card right**, **Centered, countdown below** or **Text left, photo right**. |
| Side photo | The photo for the **Text left, photo right** layout. |

## Page intro

The opening section of inner pages (Speakers, Schedule, Tickets and so on).

| Field | Notes |
|---|---|
| Breadcrumbs | Show or hide, home link text and link, and the current page text. |
| Eyebrow text, Heading, Intro text | |
| Event details | Optional date and location. |
| Primary button, Secondary button | Optional. |
| Alignment | Center or left. |
| Height | **Compact** or **Tall**. |
| Background | Background image, overlay darkness and glowing shapes. |

## Coming soon

A full-screen teaser for before tickets go on sale. Used on the **Coming soon** page and the webinar home page.

| Field | Notes |
|---|---|
| Eyebrow text, Heading, Text | |
| Event details | Date and location. |
| Countdown | Show a countdown, the date and time to count down to, and the labels. |
| Waitlist perks | A short list with icons, for example "Early-bird prices". |
| Form card | Heading, text, the HubSpot form and small print (for example your privacy note). |
| Social links | Network and profile URL. |
| Background | Background image, overlay darkness and glowing shapes. |
