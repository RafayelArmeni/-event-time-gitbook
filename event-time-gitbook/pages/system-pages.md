# System pages

System pages are pages HubSpot shows automatically, such as "page not found". Event Time styles all of them so they match your site.

| Template | Used for |
|---|---|
| **Event Time - 404 Page not found** | Missing pages |
| **Event Time - 500 Server error** | Server errors |
| **Event Time - Password prompt** | Password-protected pages |
| **Event Time - Search results** | Site search |
| **Event Time - Email subscription preferences** | Email preference center |
| **Event Time - Email subscriptions confirmation** | After someone updates their email preferences |
| **Event Time - Email backup unsubscribe** | Backup unsubscribe page |
| **Event Time - Membership login** | Private content login |
| **Event Time - Membership registration** | Private content registration |
| **Event Time - Membership reset password request** | Forgotten password |
| **Event Time - Membership reset password** | Setting a new password |

## Turn them on

1. Go to **Settings › Content › Pages** and open the **System pages** tab.
2. For each page, choose the matching **Event Time** template.
3. Save.

Email subscription pages are set in **Settings › Marketing › Email › Subscriptions**. Membership pages are set in **Settings › Content › Private content** (they need a plan that includes memberships).

The 404 and 500 pages use the **Error page** module, with a message, two buttons, site search and helpful links. The default text works for any event site.

{% hint style="info" %}
System page text is set in the template. To change it, clone the template in **Content › Design Manager** (right-click › **Clone**), edit the module values in the clone, then choose the clone as your system page.
{% endhint %}
