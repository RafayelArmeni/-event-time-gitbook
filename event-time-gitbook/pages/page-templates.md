# Page templates

Event Time has 14 page templates. Each one is a drag-and-drop page filled with demo content, so you can edit, move, add or remove any section.

![Event pages](../.gitbook/assets/event-pages.jpg)

## Home pages

| Template | Scheme | Sections |
|---|---|---|
| **Event Time - Home** | Dark | Hero with countdown card, logo strip, about with video, marquee, schedule, countdown, speakers, call to action, ticket pricing, testimonials, FAQ, newsletter, recent blog posts |
| **Event Time - Home (centered hero)** | Dark | Centered hero, logo strip, speakers, marquee, about with video, schedule, gallery, sponsors, ticket pricing, venue map, FAQ, call to action |
| **Event Time - Home (corporate summit, light)** | Light | Hero with side photo, logo strip, about with video, speakers, schedule, ticket pricing, testimonials, FAQ, call to action |
| **Event Time - Home (webinar or virtual event, light)** | Light | Registration hero with countdown and form, info cards, speakers, agenda, FAQ, call to action |
| **Event Time - Home (meetup or workshop, light)** | Light | Hero, info cards, agenda, speakers, RSVP form, venue map, newsletter |

## Event pages

| Template | Sections |
|---|---|
| **Event Time - Speakers** | Page intro, speakers, call to action, newsletter |
| **Event Time - Schedule** | Page intro, schedule tabs, countdown, speakers, newsletter |
| **Event Time - Tickets** | Page intro, ticket pricing, marquee, FAQ, call to action |
| **Event Time - Venue** | Page intro, venue map, travel info cards, gallery, hotel cards, FAQ, call to action |
| **Event Time - Sponsors** | Page intro, sponsor tiers, benefit cards, sponsorship packages, contact form |
| **Event Time - About** | Page intro, about with video, marquee, gallery, logo strip, testimonials, call to action |
| **Event Time - Contact** | Page intro, contact form, venue map, FAQ |
| **Event Time - Coming soon** | Full-screen teaser with countdown and waitlist form, logo strip |
| **Event Time - Registration thank you** | Confirmation with ticket card and add-to-calendar buttons, next-step cards, FAQ |

{% hint style="info" %}
The **Coming soon** page has a logo-only header and a slim footer, so visitors focus on the waitlist form. Its logo is set on the page itself, not in the global header. Keep the **Coming soon** and **Registration thank you** pages out of your navigation menu.
{% endhint %}
