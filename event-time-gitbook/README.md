# Welcome to Event Time

Event Time is a HubSpot CMS theme for event websites. It gives you everything from the first "save the date" page to the thank-you page after registration.

**Live demo:** [pixtheme.com/event-time-demo](https://www.pixtheme.com/event-time-demo)

![Five home page layouts](.gitbook/assets/home-layouts.jpg)

## What's included

| | |
|---|---|
| **Home pages** | 5 layouts: dark conference, centered keynote, light corporate summit, webinar, meetup |
| **Event pages** | About, Speakers, Schedule, Tickets, Venue, Sponsors, Contact, Coming soon, Registration thank you |
| **Blog** | Blog listing and blog post templates |
| **System pages** | 404, 500, password prompt, search results, email subscription pages and membership pages |
| **Modules** | 22 drag-and-drop modules plus the site header and footer |
| **Sections** | 10 ready-made sections you can drop into any page |

## Requirements

* A HubSpot account that can create website pages. Event Time works with website pages, landing pages and the HubSpot blog. Membership pages need a Content Hub plan that includes memberships.
* No coding is needed. Everything is edited in the HubSpot page editor and theme settings.
